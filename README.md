## Working conventions

- Keep assignment work alongside the corresponding assignment materials.
- Use [Notes](Notes/) for personal explanations, derivations, and lecture summaries.
- Keep datasets, model checkpoints, generated outputs, virtual environments, and credentials out of Git; common paths are covered by `.gitignore`.
- Lecture PDFs and supplied solution PDFs are tracked. Generated LaTeX PDFs are not globally ignored, so review them before committing.

No Python environment is defined yet. Dependencies and run instructions will be added when programming work begins.
